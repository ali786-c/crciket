## 📅 August 18, 2026: Unified Homepage Architecture Decision
*   **Unified Dashboard Pattern**: Decided to build a single, unified Homepage/Dashboard for all users (Admins, Captains, Players, Guests) instead of separate panels.
*   **Dynamic Scoping**: UI elements (such as create buttons, draft panel prompts, and user career details) will render dynamically based on the current user's active roles and permissions retrieved from `GET /api/v1/auth/me`. A single user identity can function both as an Administrator and a Player concurrently.
*   **Homepage Flow Finalized**: Mapped the detailed vertical hierarchy of the Home screen: Horizontal Live/Recent Matches Row -> "My Profile" Quick Access Card (links to full Career stats profile) -> Live Tournaments List -> Contextual Admin/Captain Toolbox. Logged in [mobile_screens_plan.md](file:///c:/Users/Muhammad%20Aliyan/Downloads/cricket-draft-source/cricket-draft-mobile/mobile_screens_plan.md).
*   **Friendly Matches & Tournament Creation Flows**: Added layout plans for "Create Single Match" (friendly matches without tournament constraints) and "Create Tournament" (collecting Name, City, Season, Start/End Dates, and Ball Type).
*   **"My Tournaments" Hub Tabs**: Finalized the multi-tab structure for the Tournament Dashboard Hub (Home, Teams/Rosters, Fixtures/Matches, Points Table, and Statistics).
*   **Tournament Home Tab Highlights**: Integrated recent match results lists, top batsman/bowler aggregate previews, and a conditional Honors Board (Championship Winner, Runner-up, and Man of the Tournament) for completed leagues.
*   **Team Profile Hub Layout**: Finalized the multi-tab Detailed Team Profile Screen layout (Screen B.3.1) featuring Home (Overview with top performers), Players (roster listing with owner-only add/delete permission boundaries), Matches (scheduled & completed history), Tournaments (participation logs), and Statistics (team performance analytics). Tapping a player opens their profile.
*   **Tournament Hub Screen Details**: Defined granular layouts for the Matches tab (scheduled/completed division, click navigation), Points Table tab (standard Pos, P, W, L, T, NR, Pts, NRR column headers, and qualifying highlight zones), and Statistics tab (Most runs, most wickets, highest individual scores, best bowling spells, boundary hit counts, and MVP leaderboards).
*   **Exhaustive Statistics Catalog**: Broadened the Statistics tab (Screen B.6) layout plans to encompass 18 distinct metrics: batting average/strike rate/centuries, bowling economy/strike rate/dots/maidens/5w spells, fielding catches/stumpings/run-outs, and highest partnership run records.
*   **Match Center (Screen C.3) Layout Finalized**: Completed layout specs for the 4-tab Match Center (Summary, Scorecard, Stats, and Super Stars). Summary uses strict headers shorthand (R, O, M, W) for current batsman/bowler lists, displays bold scorelines, CRR/Projected scores, and partnership stats. Scorecard includes innings toggles. Super Stars displays the top 4 performers computed via dynamic MVP algorithms.
*   **Summary Screen Integrated Keyboard**: Modified Match Center (Screen C.3) back to 4 main tabs, consolidating the scoring keyboard directly as an anchored bottom panel within the Summary Tab (conditionally visible only to the authorized Admin/Scorer), making live scoring faster and keeping the navigation structure cleaner.
*   **Player Profile Layout Detailed**: Finalized the multi-tab Detailed Player Profile Screen (Screen D.1) layout: Overview (bio, batting runs/avg/HS, bowling wickets/avg/best, fielding catches/stumps/run-outs), Stats (detailed batting/bowling/fielding grid), Matches (match participation logs), Teams (club history), and Tournaments.
